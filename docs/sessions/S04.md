- field ที่ไม่มีค่าจะไม่อยู่ใน draft เลย (ไม่ใช่ `undefined`) เพื่อให้ map ลง Firestore ได้ตรง ยังไม่เขียน Firestore (A01)

## คำถามค้าง (ไม่เดา)

1. **Key ของหมวด** — spec มีแค่ชื่อภาษาไทย 7 หมวด ตอนนี้ใช้ชื่อไทยตรงตัวเป็นค่าที่เก็บ ถ้าต้องการ key คงที่ (เช่น `damage`) เพื่อกันปัญหาเปลี่ยนชื่อในอนาคต ต้องกำหนดก่อน A01 บันทึกลง Firestore
2. **หมวดของงานซ่อม/เอกสาร** — spec บังคับหมวดเฉพาะ `gm_task` (manual) และงานต่ออายุใช้ Admin mapping ส่วน `maintenance`/`document_*` ไม่ระบุ ตอนนี้ไม่ตั้งหมวดให้ ต้องการ mapping อัตโนมัติ (เช่น ซ่อม → ทรัพย์สินและอาคารสถานที่) หรือไม่
3. **รูปแบบคำตอบเรื่องลับ** — ตอนนี้เป็นคำตอบบังคับ `contract`/`personnel`/`general` และ `sensitivity_reason` เก็บเป็น `contract`/`personnel` ถ้าไม่ตอบจะปฏิเสธแทนการตั้งไม่ลับ ยืนยันรูปแบบนี้ หรือต้องการ `sensitivity_reason` เป็นข้อความอิสระ
4. **แก้ธงลับตอนสร้าง** — C6 ให้ปลดธงได้เฉพาะ GM Admin พร้อมเหตุผล แต่ไม่บอกว่าตอนสร้าง ผู้สร้างเปิดลับเองสำหรับเรื่อง `general` หรือปิดลับเรื่องสัญญา/บุคคลได้หรือไม่ ตอนนี้ใช้ค่าเริ่มต้นเท่านั้น ไม่รับการ override
5. **งานซ่อมลับได้ไหม** — ตอนนี้งานซ่อมไม่ลับเสมอตอนสร้าง (C6 ระบุเฉพาะสัญญา/บุคคล)
6. **Role `viewer` เปิดคำขอเองได้ไหม** — ตอนนี้ทุก role เปิดคำขอของตัวเองได้ ส่วน `gm_task`/เปิดแทน จำกัด GM
