### API (GM Admin เท่านั้น — ตรวจทุกครั้งหลังยืนยัน token + `access/{uid}`; role อื่น 403 `GM_ADMIN_ONLY`)

- `GET /api/admin/places` (อ่านแบบมีเพดาน: สถานที่ 50, บริเวณ/QR 1000), `GET /api/admin/calendar`, `GET /api/admin/health` — อ่านครั้งเดียวตอนเปิดหน้า/กด “ตรวจอีกครั้ง” ไม่มี listener
- `POST /api/admin/commands` `{command_id (UUID), type, payload}` สัญญาเข้มงวด (`parseAdminCommand`) — idempotent แบบเดียวกับคำสั่งงาน (`commands/{id}` + fingerprint: key เดิม body เดิม → ผลเดิม `replayed`, body อื่น → 409 `COMMAND_ID_CONFLICT`); transaction เดียว อ่านก่อนเขียน; กติกาใน `@gm/domain`
  - `seed_places` สร้างเฉพาะที่ยังไม่มี (ไม่ทับชื่อ/สถานะที่ Admin แก้แล้ว); `add_area` (ชื่อ 1–60 ตัว ไม่ซ้ำในสถานที่เดียวกัน รวมบริเวณที่ปิดแล้ว ไม่สนตัวพิมพ์/ช่องว่าง → 409 `AREA_LABEL_TAKEN`; สถานที่ปิด → 422 `LOCATION_INACTIVE`); `rename_area`; `set_area_active` / `set_location_active` (**ปิดแทนการลบ** D-S08-3: เอกสารยังอยู่ งานเก่ายังอ่านชื่อได้)
  - `create_qr` (บริเวณที่เปิดอยู่และยังไม่มี QR → 409 `AREA_HAS_QR`); `move_qr` (รหัสเดิมชี้บริเวณใหม่ที่เปิดอยู่และยังไม่มี QR; บริเวณเดิมว่างให้สร้างใหม่ได้ — **ไม่ต้องพิมพ์ใหม่**); `set_qr_active`
  - `set_open_weekdays`, `put_holiday` (เพิ่ม หรือ `replaces` = แก้วันที่/ชื่อ; วันซ้ำ → 409 `HOLIDAY_EXISTS`; ปีนอก ค.ศ. 2000–2100 → 422 `HOLIDAY_YEAR_OUT_OF_RANGE` ไม่เขียนอะไร — D-S01-6), `remove_holiday`; ครั้งแรกสร้างปฏิทินจันทร์–ศุกร์
  - `set_reminder_time` (`HH:MM`)
- FU-30: `follow_up` + `remind` อ่าน `settings/notifications.working_morning_time` ใน transaction เดียวกัน (ก่อนเขียน; อ่านเฉพาะเมื่อมีการเตือน) แทน 09:00

### หน้าจอ (UI-12; มือถือ: การ์ด/รายการ, desktop ≥ 1024px: ตาราง — เลือกแสดงแบบเดียวด้วย media query ไม่ซ่อน DOM ซ้ำ)

- **สถานที่และบริเวณ** `/admin/locations`: 5 สถานที่ + จำนวนบริเวณ/ที่ใช้งาน + สถานะเป็นคำ; ว่าง → “ยังไม่มีสถานที่” + “เพิ่ม 5 สถานที่ตาม brief”; `/admin/locations/:id`: เพิ่มบริเวณ, แก้ชื่อในแถว, ปิด/เปิดใช้งาน, ปิด/เปิดสถานที่; ผิดพลาดบอกเหตุผล (role=alert) และ**คงค่าที่พิมพ์**
- **QR ของบริเวณ** `/admin/qr?location=&area=`: เลือกสถานที่ → บริเวณ → preview ชื่อ “WH300 · ห้องแพ็คชั้น 1”, รูป QR (วาดในหน้าด้วย `qrcode-generator` MIT, error correction M — ไม่ใช้บริการ QR ภายนอก/รายเดือน), ลิงก์ `{base}/q/{qr_id}`, “เปิดลิงก์ทดสอบ”, “พิมพ์ / ดาวน์โหลด”, ปิด/เปิด QR, ย้าย QR; บอกว่า “หน้านี้ไม่สร้างงานแจ้งซ่อม”; บริเวณปิด → ให้เลือกใหม่
- **พิมพ์ QR** `/admin/qr/:qr_id/print`: แผ่นพิมพ์ (ชื่อ + QR + ลิงก์) ปุ่ม “พิมพ์” (ซ่อนเมนูตอนพิมพ์) และ “ดาวน์โหลด SVG”; **ลายน้ำ “ตัวอย่าง ห้ามพิมพ์ติดจริง” บนหน้าพิมพ์และในไฟล์ SVG** พร้อมคำอธิบาย จนกว่า base URL ของ build จะเป็นโดเมน prod `https://gm.tdfb.co` (`VITE_GM_PUBLIC_BASE_URL`, ตรวจด้วย `qrPrintMode`) — [FU-42](../FOLLOW-UPS.md)
- **ปฏิทินบริษัท** `/admin/calendars`: คำอธิบาย “1 วันทำการ = สะสม 24 ชั่วโมงบนวันที่เปิดทำการ” และ “มีผลภายใน 15 นาที ไม่เปลี่ยน SLA ของงานเดิม”; วันทำงานในสัปดาห์ (ช่องเลือก 7 วัน ขนาดแตะ ≥ 44px); วันหยุด: กรอก วัน / เดือน / **ปี พ.ศ.** → preview “จะบันทึกเป็น ศุกร์ 1 ม.ค. 2570” → เก็บ ค.ศ.; ปีที่ดูเหมือน ค.ศ. (2000–2100) → “ปี 2027 ดูเหมือนเป็น ค.ศ. กรอกเป็น พ.ศ. เช่น 2570” **ไม่แปลงเอง** และไม่ส่ง; ปีที่แสดง (พ.ศ.) เลื่อนได้; รายการตามเดือน (มือถือ) / ภาพรวม 12 เดือน + รายการ (desktop); แก้/ลบ; บันทึกแล้ว “บันทึกแล้ว มีผลภายใน 15 นาที” (คำนวณ stale ใหม่ใน tick ถัดไปตาม D-A05-3 — emulator test ผ่านคำสั่ง Admin จริง); “ตรวจก่อน pilot: ธ.ค. 2569 – ม.ค. 2570”; เวลาส่งการเตือน (FU-30)
- **สุขภาพระบบ** `/admin/health` (เมนู Admin ใหม่ — `ADMIN_SECTIONS` เพิ่ม `health`): สถานะรวม ปกติ / ควรตรวจ / ต้องแก้ไข (คำ + สี), tick ล่าสุด (**เกิน 30 นาที หรือยังไม่เคยเสร็จ → แดง**), แอป Slack (`app_error` → แดง + รหัส + เวลาเริ่ม + “ส่งทางอีเมลแทน”, D-A08-6), job ที่ `failed` (แดง, D-A05-5), การแจ้งเตือน `failed` / `delivery_unknown` / ค้างเพดานอีเมล (ควรตรวจ), ส่งทางอีเมลแทน Slack แยกตาม `slack_fallback_code` (+ คำแนะนำ) — **จำนวนและรหัสเท่านั้น ไม่มีผู้รับ**
