## ส่วนที่ 2 — A09

### Login (UI-01, Part 6 §6.5)

- `signInWithPopup` (Google, `hd: tdfb.co` เป็นแค่ตัวช่วยเลือกบัญชี) ผ่าน Auth emulator; popup ถูกบล็อก → redirect
- หลัง login อ่าน claims แล้วใช้ `isCorporateGoogleToken` ตัวเดียวกับ API/Rules (D-S10-5): ไม่ผ่าน (โดเมนอื่น, `tdfb.co.th`, ไม่ยืนยันอีเมล, ไม่ใช่ Google) → **sign out ทันที** + ข้อความ “<อีเมล> ไม่ใช่บัญชีบริษัท … ใช้บัญชี @tdfb.co เท่านั้น ระบบออกจากระบบให้แล้ว”
- ผ่าน → listener เดียวบน `access/{uid}` (Rules ให้อ่านของตัวเอง แม้บัญชีถูกปิด, D-S09-6): ไม่มีเอกสาร → “บัญชีนี้ยังไม่ได้เปิดใช้งาน”; `enabled` ไม่ใช่ `true` → “บัญชีถูกปิด” (role ใดก็ตาม); role ไม่รู้จัก/ไม่มี `person_id` → ไม่ให้เข้า (ไม่เดา role); ปิดบัญชีระหว่างใช้ → หน้า “บัญชีถูกปิด” ทันที — ทั้งสองหน้ามีเหตุผล + “เปลี่ยนบัญชี” + กล่องติดต่อ ไม่มีเมนู/บอร์ด
- ข้อความผิดพลาดแยก 3 แบบ: ยกเลิก (“ยกเลิกการเข้าสู่ระบบแล้ว”), ไม่สำเร็จ (“เข้าสู่ระบบไม่สำเร็จ”), ไม่ใช่บัญชีบริษัท; ระหว่างตรวจบัญชีแสดง “กำลังตรวจบัญชี…” และกล่องติดต่อยังใช้ได้
- `/login?next=` กลับหน้าที่เปิดค้างไว้ (เฉพาะ path ในแอป; `//host`, `https:`, `/login` → หน้าแรก); มี session แล้วเปิด `/login` → เข้าเลย
- ลำดับมือถือตาม UI-01: ชื่อบริการ → คำอธิบายสั้น → “เข้าสู่ระบบด้วย Google” → “ใช้บัญชี @tdfb.co” → กล่องติดต่อ; desktop เป็นกล่องกลางกว้าง 440px

### ช่องทางติดต่อก่อน login (A1.3, Part 6 §6.4 “pre-login contact เป็น safe subset”)

- `GET /api/public/contact` ไม่ต้อง login ไม่อ่าน token: คืนเฉพาะ `content_pages/contact.prelogin_contacts[]` ที่ Admin ใส่ — 4 field แสดงผล (`label`, `contact_name` → `name`, `phone` เบอร์ล้วน, `detail`) บรรทัดเดียว ตัดความยาว ไม่เกิน 5 รายการ; field อื่นของเอกสาร (เนื้อหาหลัง login, อีเมล, Slack) ไม่ออก; อ่าน Firestore ไม่เกินนาทีละครั้งต่อ instance; CORS เฉพาะ origin ของแอปเหมือนทุก route; log มีแค่ชื่อ route/status
- หน้าเว็บแสดงเบอร์เป็นลิงก์ `tel:`; ยังไม่ตั้ง → “ผู้ดูแลยังไม่ได้ตั้งช่องทางติดต่อสำหรับหน้านี้”; โหลดไม่ได้ → “ลองใหม่”; ไม่มีฟอร์มส่งงานแบบไม่ระบุตัวตน (“ทีม GM จะช่วยเปิดเรื่องให้”)
- ที่แก้ข้อมูลนี้คือ `/admin/content` → [FU-39](../FOLLOW-UPS.md) (A23)

### 4 roles, เมนูและ route (Part 2 §2–3.1, Part 3 §0.2)

- `@gm/domain` `navigationFor` / `canOpenArea`: ทุก role ที่ใช้งานได้มี หน้าแรก / คำขอของฉัน / แจ้งซ่อม / บอร์ด / ติดต่อ GM — **Viewer มี “แจ้งซ่อม” ตาม D-S04-6** (ใหม่กว่า “Viewer ใช้เมนูอ่าน 4 รายการ” ของ Part 3 §0.2; Q-A09-2); GM Staff/Admin เพิ่ม “สร้างงาน GM / เปิดแทน”; GM Admin เท่านั้นมี Admin 5 หน้า (สถานที่และบริเวณ, QR ของบริเวณ, รายชื่อพนักงานและสิทธิ์, ปฏิทินบริษัท, เนื้อหาติดต่อทีม GM / FAQ)
- เมนูซ่อนตาม role และ **router ปฏิเสธ URL ตรง** (`/admin/*`, ฟอร์ม GM) ด้วย `canOpenArea` → “ไม่มีสิทธิ์เข้าหน้านี้”; path ที่ไม่รู้จัก → “ไม่พบหน้านี้”; หน้าจอซ่อนเพื่อความสะดวกเท่านั้น สิทธิ์จริงยังตรวจที่ API และ Rules (หน้าใน A09 ไม่อ่านข้อมูลงานใดเลย)
- route ของ Part 2 §3.1: `/login`, `/`, `/my-requests`, `/requests/new?type=maintenance&origin=requester`, `…type=gm_task&origin=gm_initiated`, `…type=maintenance&origin=gm_on_behalf`, `/requests/:id`, `/board`, `/team`, `/admin/{locations,qr,users,calendars,content}`; หน้าที่ task อื่นจะทำแสดง “ยังไม่เปิดใช้งานในรุ่นนี้” (ไม่มีข้อมูลตัวอย่าง ไม่ fetch อะไร) — `/q/:qr_id` รอ A12

### โครงหน้า (Part 3 §0.1–0.2, P2, F6, prototype)

- **มือถือ (< 1024px)**: top bar (โลโก้ + “เมนูเพิ่มเติม”), bottom nav หน้าแรก / คำขอของฉัน / [แจ้งซ่อม ปุ่มกลางสีมัทฉะ มีไอคอน+ข้อความ แตะเดียวเข้าฟอร์ม] / บอร์ด / ติดต่อ GM — 80px, **64px เมื่อจอสูง ≤ 700px**, + safe area; ป้ายที่ยาวเกินขึ้นบรรทัดสองระหว่างคำ ไม่ตัดด้วย “…”; เนื้อหามี padding ล่างเท่า nav จึงไม่ถูกบัง; **ซ่อน bottom nav ตลอดฟอร์มแจ้งซ่อม** (รวมเปิดแทน) มีปุ่ม “ออกจากฟอร์ม”; “เมนูเพิ่มเติม” เป็น sheet (dialog) มีชื่อ/อีเมล/role, “สร้างงาน GM / เปิดแทน” (GM), Admin (GM Admin), “ออกจากระบบ”

### Logout (เครื่องใช้ร่วมกันหน้างาน)

`signOut` (ข้อมูลผู้ใช้ใน IndexedDB ของ Firebase หาย) → `terminate` Firestore (cache เป็น memory อย่างเดียว ไม่มีใน IndexedDB) → ล้าง `localStorage`, `sessionStorage`, Cache Storage ทั้งหมดของ origin → โหลดหน้า login ใหม่ (state ใน memory หายด้วย); ย้อนกลับ (back) ไม่เห็นแอป; “เปลี่ยนบัญชี” ใช้ขั้นตอนเดียวกัน

### Firebase / config (emulator เท่านั้น)

`apps/web/src/config.ts` รับเฉพาะ project `demo-*` และ endpoint บนเครื่อง (Auth/Firestore emulator, API `127.0.0.1`/`localhost`) — ค่าอื่น build แล้วหยุดตั้งแต่เริ่ม ค่าจริงรอ P7-INFRA-01 → [FU-37](../FOLLOW-UPS.md); Firestore `memoryLocalCache` (ไม่มี private cache ในเครื่อง); ปิดแถบเตือน emulator ของ Auth (บัง bottom nav)

## คำถามค้าง (ไม่เดา — ทำตามข้อที่ระบุไว้ก่อน รอยืนยัน)

1. **Q-A09-1 ผูกบัญชีตอน login ครั้งแรก** — D-S08-4 ให้ server ผูก UID กับ verified email ตอน login ครั้งแรก แต่ยังไม่มีที่เก็บ role ของคนที่ยังไม่เคย login (`access/{uid}` สร้างได้หลังรู้ UID เท่านั้น) — A09 จึงแสดง “บัญชีนี้ยังไม่ได้เปิดใช้งาน” เมื่อไม่มี `access/{uid}`; เสนอ: A10 นำเข้า role/สถานะใน `people/{person_id}` แล้ว API สร้าง `access/{uid}` เมื่อ login ครั้งแรกด้วย verified email ที่ตรงรายชื่อ — ยืนยันหรือกำหนดที่อื่น ([FU-38](../FOLLOW-UPS.md))
2. **Q-A09-2 Viewer กับ “แจ้งซ่อม”** — ใช้ D-S04-6 (Viewer เปิดคำขอของตัวเองได้, ใหม่กว่า) แทน Part 3 §0.2 (Viewer ใช้เมนูอ่าน 4 รายการ) → Viewer มีปุ่มแจ้งซ่อม — ยืนยัน
3. **Q-A09-3 “สร้างงาน GM / เปิดแทน”** — เป็นปุ่มเดียวไปฟอร์มสร้างงาน GM; ฟอร์มเปิดแทน (`origin=gm_on_behalf`) มี URL ของตัวเองแต่ยังไม่มีเมนูแยก — ให้ A21 ทำฟอร์มเดียวที่สลับได้ หรือแยกสองเมนู
4. **Q-A09-4 ช่องทางติดต่อก่อน login** — ใช้ `content_pages/contact.prelogin_contacts[]` (`label`, `contact_name`, `phone`, `detail`, ไม่เกิน 5) — ต้องการช่องอื่นไหม เช่น LINE OA หรือลิงก์ (ตอนนี้แสดงเป็นข้อความใน `detail` ได้ แต่ไม่เป็นลิงก์)
5. **Q-A09-5 “เมนูเพิ่มเติม” บนมือถือ** — Part 2 ให้ Admin อยู่ใน “เมนูเพิ่มเติม” แต่ไม่ได้ระบุตำแหน่ง (prototype ไม่มี) → ปุ่มที่ top bar เปิด sheet: บัญชี, สร้างงาน GM, Admin, ออกจากระบบ — ยืนยัน
6. **Q-A09-6 การค้างการเข้าสู่ระบบ** — ใช้ค่าเริ่มต้นของ Firebase: อยู่ในระบบบนเครื่องจนกด “ออกจากระบบ” (เครื่องร่วมกันต้องกดออก) — หรือให้ออกเองเมื่อปิด browser (session เท่านั้น ผู้ใช้มือถือต้อง login บ่อยขึ้น)
7. **Q-A09-7 utility override “input h 2”** (TEST-CHECKLIST §4 / P1) — A09 ไม่มีช่องกรอก และไม่ชัดว่า “h 2” หมายถึง `h-2` (8px) หรืออย่างอื่น — ตรวจ 3 กรณีที่เหลือบน element จริงแล้ว (ลิงก์ `text-brand-fg`, ปุ่ม `text-caption font-semibold`, ปุ่มหลัก `px-8`); ขอค่าที่คาดหวังของกรณี input
