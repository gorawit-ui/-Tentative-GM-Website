## Dev deploy guard

`scripts/deploy-dev.mjs` อ่าน `infra/deploy/dev-targets.json` (ผู้ดูแลรับรอง) แล้วตรวจตามลำดับ ทั้งหมดก่อน network/child process ใดๆ:

1. `GM_DEV_PROJECT_ID` ว่าง → `TARGET_EMPTY` (ไม่ fallback default/ambient project)
2. รูปแบบ project ID ผิด → `TARGET_INVALID`
3. อยู่ใน denylist หรือชื่อแบบ prod → `TARGET_PROD`
4. ไม่อยู่ใน allowlist ที่ผู้ดูแลอนุมัติ → `TARGET_NOT_APPROVED` (ไม่เชื่อ suffix `-dev`)
5. ตัวแปร project ของ gcloud/Firebase ชี้ project อื่น → `AMBIENT_PROJECT_MISMATCH`
6. มี key file/token override (`GOOGLE_APPLICATION_CREDENTIALS`, `FIREBASE_TOKEN`, …) → `CREDENTIAL_OVERRIDE_SET` (แสดงชื่อตัวแปร ไม่แสดงค่า)
7. `.firebaserc` มี default project → `DEFAULT_PROJECT_CONFIGURED`
8. ยังไม่มี adapter ที่อนุมัติ → `ADAPTER_MISSING` (P7-INFRA-01)

Adapter ในอนาคตต้องเรียก `assertExplicitProject()` กับทุก CLI call (`--project` ครั้งเดียวและตรง target) ไม่มีคำสั่ง deploy prod ใน repo; config เปลี่ยนได้ผ่าน review ของผู้ดูแลเท่านั้น
