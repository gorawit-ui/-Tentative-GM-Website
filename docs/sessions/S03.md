| ฟังก์ชัน | กติกา |
|---|---|
| `staleState(lastUpdatedAt, now, calendar)` | `{ elapsed (raw), thresholdAt, stale }`; stale เมื่อ elapsed **มากกว่า** 3 วันทำการ (Part 6 “เกิน”); ครบ 3 วันทำการพอดียังไม่ stale |
| `autoCloseDue(completedAt, calendar)` | `completed_at` + 3 วันทำการ (C5) |
| `isAutoCloseDue(completedAt, now, calendar)` | true เมื่อสะสม **อย่างน้อย** 3 วันทำการ (Part 6 “ครบ”) |
| `formatBusinessDuration(raw, context)` | context `waiting` → “ไม่ถึง 1 วันทำการ” / “X วันทำการ”; `last_update` → “อัปเดตล่าสุดไม่ถึง 1 วันทำการที่แล้ว” / “อัปเดตล่าสุด X วันทำการที่แล้ว”; `gm_stale` → “ไม่ขยับ X วันทำการ · ถึงเวลาติดตาม” (ใช้ได้เฉพาะ raw > 3 วันทำการ); X ปัดลงเป็นจำนวนเต็ม (F4) |
