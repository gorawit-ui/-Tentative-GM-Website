### ประมาณการ query บอร์ดเทียบเพดาน 200 (D-S10-4)

ฐานจาก Part 6 §6.4/§6.13 และ Part 7: งานใหม่ 20 งาน/วันทำการ (440/เดือน), ผลลัพธ์บอร์ดเฉลี่ย 200 การ์ด/คน; query แยกตาม §6.11

| Query | ประมาณการ | เทียบ 200 |
|---|---|---|
| งานเปิด (`queued`/`in_progress`/`waiting`) | 20 × จำนวนวันทำการที่งานค้างเฉลี่ย: ค้าง 5 วัน ≈ 100, ค้าง 10 วัน ≈ 200 | **เสี่ยงเกิน** เมื่องานค้างเฉลี่ยเกิน ~10 วันทำการ หรือเมื่อนำการ์ด Trello เก่าเข้า |
| เสร็จรอยืนยัน (`completed` ไม่มี `closed_at`) | ≤ 20 × 3 วันทำการ (ปิดอัตโนมัติ) ≈ 60 | ต่ำกว่า |
| ปิดแล้ว 7 วัน | ≈ 20 × 5 วันทำการ ≈ 100 | ต่ำกว่า |
| ยกเลิก 7 วัน | หลักหน่วย–สิบ | ต่ำกว่า |
| รวมทุกส่วนใน query เดียว | ≈ 100 + 60 + 100 ≈ **260** | **เกิน** → ต้องแยก query ตามส่วน (ตาม §6.11) ห้ามรวม |

ข้อเสนอสำหรับ A-task บอร์ด: แยก query ตามส่วนเสมอ, query งานเปิดใช้ `limit(200)` + ปุ่ม/cursor “โหลดเพิ่ม” และแสดงว่ายังมีอีก ไม่ตัดเงียบ (§6.11 “ไม่ silently cap”); หน้า “ดูทั้งหมด” ใช้ `pageLimit()` (50)
