## คำถามค้าง (ไม่เดา — ทำแบบแคบที่สุดไว้ก่อน)

1. **ป้ายฝ่ายที่รอบนสรุปสาธารณะ** — Part 6 ให้ใช้ “safe label ที่ GM ยืนยัน หรือ generic kind” แต่ยังไม่มี field safe label ตอนนี้ใช้ป้ายกลางตามชนิดทั้งหมด (รวมคนและทีมภายใน) ควรแสดงชื่อพนักงาน/ชื่อทีมภายในบนบอร์ดสาธารณะหรือไม่ และต้องมีช่องให้ GM ยืนยันชื่อฝ่ายภายนอกหรือไม่
2. **Viewer ที่ถูกเพิ่มเป็น related ในงานลับ** — Part 6 §6.5 และ Part 2 F05 ให้ related (รวม Viewer) อ่านรายละเอียดได้ แต่ PRD บอกว่า Viewer “ไม่เปิดงานลับ” ตอนนี้ทำตาม Part 6/F05 (อ่านได้เมื่อถูกเพิ่มชัดเจนและยืนยันสิทธิ์งานลับแล้ว)
3. **`calendars` / `sla_policies` / `settings`** — Part 6 เขียน “อ่านค่าที่จำเป็นตามสิทธิ์” fixture ตอนนี้ปฏิเสธ client ทั้งหมด (ให้ API ส่งค่าที่จำเป็น) ถ้าหน้าเว็บต้องอ่านวันหยุดตรงจาก Firestore ต้องระบุ document/field ที่เปิด
4. **ชื่อ collection ตัวนับ “งานภายใน”** — Part 6 ไม่ได้ตั้งชื่อ ใช้ `board_counters/public`; และงานลับที่พ้นกรอบ 168 ชั่วโมงโดยไม่มีการเขียน ต้องคำนวณใหม่โดย tick ของ scheduler หรือคำนวณตอนอ่านผ่าน API
5. **ผู้ขอ/related อ่าน `requests/{id}` ตรง** — Rules ป้องกันราย field ไม่ได้ จึงเห็น `watcher_ids`/`related_person_ids` (อีเมล) และ `sensitivity_note` ด้วย ยอมรับได้หรือควรย้าย field เหล่านี้ไปที่ GM-only/ผ่าน API
6. **บัญชีปิดใช้งานอ่าน `access` ของตัวเอง** — ทำตาม pseudocode “self read” เพื่อให้หน้าเว็บบอกว่าบัญชีถูกปิด ยืนยันได้หรือไม่
7. **“ฝ่ายที่รอตอบกลับแล้ว” บนการ์ดสาธารณะ** — A2.1 ให้การ์ดแสดง แต่ allowlist สาธารณะของ Part 6 ไม่ได้ระบุ ตอนนี้อยู่ในสรุปของ GM เท่านั้น
8. **ขอบ 168 ชั่วโมง** — ปิดครบ 168 ชั่วโมงพอดีถือว่าพ้นกรอบ (`closed_at > now − 168h` ยังแสดง) ใช้ได้หรือไม่
