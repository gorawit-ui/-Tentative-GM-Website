## รันซ้ำ

ติดตั้ง Playwright สำหรับ Node แล้วตั้ง GM_CHROMIUM_PATH ให้ชี้ Chromium ในเครื่อง จากโฟลเดอร์แพ็กเกจ:

```bash
python prototype-src/build.py
node prototype-qa/patch-check.cjs
```

ผล JSON: prototype-qa/patch-report.json ส่วนชุดผล 83 ข้อก่อน Patch เป็น baseline ของฉบับก่อนหน้า ไม่ใช่ผลทดสอบแทนเกณฑ์ F1–F6 ใหม่นี้

## ขอบเขต

ใช้ viewport emulation ไม่ใช่การทดสอบ Android/iOS เครื่องจริง ปุ่มเลือกภาพใช้ file chooser จริงใน Chromium แต่ยังไม่ได้ตรวจเมนูกล้อง/แกลเลอรีของระบบปฏิบัติการมือถือแต่ละรุ่น

prototype เป็นข้อมูลจำลอง ไม่มี backend ไม่มีการส่ง Slack/email จริง การทดสอบครั้งนี้ไม่ใช่การตรวจ security หรือ production infrastructure และยังไม่เริ่ม Part 6
