# Part 5 — Patch

ฉบับแก้ F1–F6 ใช้แทนพฤติกรรมเดิมเฉพาะส่วนที่ระบุด้านล่าง ยังไม่เริ่ม Part 6

## F1. บอร์ดมือถือ

- ตัวกรองย่อเป็น chip เลื่อนแนวนอน: ทั้งหมด / ของฉัน / ยังไม่มอบหมาย พร้อมปุ่มตัวกรองเปิด sheet สำหรับสถานที่ ผู้รับผิดชอบ ประเภท และค้นหาด่าน B
- ตัวกรองที่ใช้อยู่แสดง chip กดลบได้ การปิด sheet โดยไม่กดใช้ตัวกรองไม่เปลี่ยนค่าที่ใช้อยู่
- ปุ่มสร้างงาน GM ย่ออยู่ข้างชื่อหน้า Desktop คงตัวกรองเดิม
- ตรวจที่ 360×640: การ์ดแรกเต็มใบอยู่ระหว่าง y=236–403px เหนือ bottom nav ที่เริ่ม y=576px โดยไม่ต้องเลื่อน

## F2. การ์ดกระชับ

- ไม่แสดงแถวสถานที่ซ้ำเมื่อชื่องานมีสถานที่อยู่แล้ว งานที่ชื่อไม่มีสถานที่ยังแสดงแถวดังกล่าว
- รวมผู้รับผิดชอบและอัปเดตล่าสุดเป็น meta บรรทัดเดียว พร้อมลดช่องว่างภายในการ์ด
- การ์ดแจ้งซ่อมรอคิวในชุดข้อมูลตัวอย่างสูงประมาณ 167px บนมือถือ และ 171px บน desktop
- ที่ 390×844 เห็น 3 ใบเต็มในจอแรก ใบที่สามจบ y=754px ก่อน bottom nav y=764px ปุ่ม action ทุกปุ่มสูงอย่างน้อย 44px

## F3. เลือกฝ่ายที่รออย่างชัดเจน

- ทั้งฟอร์มบนการ์ดและฟอร์มสร้างงาน GM เริ่มรอใคร/พนักงานที่รอเป็นค่าว่าง “เลือก...” ไม่เลือกคนแรกอัตโนมัติ
- แสดงตัวเลือกแจ้งเตือนหลังเลือกคนหรือผู้ติดต่อทีมแล้วเท่านั้น แสดงข้อความเพิ่มสิทธิ์รายละเอียดเมื่อเปิดการแจ้ง
- ปุ่มยืนยันปิดไว้จนข้อมูลที่จำเป็นครบ สำหรับทีม ผู้ติดต่อยังไม่บังคับตามกติกาเดิม
- งานลับต้องยืนยันให้สิทธิ์แยก การเปลี่ยนผู้รับล้างการยืนยันให้สิทธิ์เดิมเพื่อให้ตรวจชื่อใหม่อีกครั้ง
- มี validation ตอนบันทึกด้วย ไม่อาศัยเฉพาะปุ่ม disabled

## F4. ข้อความและเวลา

- ป้าย GM ใช้ “ไม่ขยับ X วันทำการ · ถึงเวลาติดตาม” แทน stale; ผู้ไม่มีสิทธิ์ GM ยังเห็นข้อความกลาง
- เวลาแสดงเป็นจำนวนเต็มปัดลง เช่น 4.1 แสดง 4 วันทำการ ค่าที่คำนวณ stale/SLA ยังใช้ค่าจริง ไม่ปัดก่อนตัดสิน
- รอใครบ่อยที่สุดแสดงเวลารอสะสมเป็นวันทำการตามปฏิทินบริษัทในเดโม และหยุดช่วงรอที่ responded_at ตามเดิม

## F5. แนบรูป

- ซ่อน native file input ใช้ปุ่ม “ถ่ายรูป / เลือกรูป” เปิดตัวเลือกรูปด้วย accept="image/*"
- รายการแสดง “รูปที่ 1”, “รูปที่ 2” พร้อมชื่อไฟล์และสถานะภาษาไทย
- คงการย่อด้านยาวไม่เกิน 1600px ความคืบหน้ารายรูป และการส่งงานเมื่อรูปบางรูปยังไม่สำเร็จ

## F6. การนำทางมือถือ

- ซ่อน bottom nav ตลอดฟอร์มแจ้งซ่อม รวมหน้าคั่นงานซ้ำ และแสดงคืนเมื่อส่งงาน/ติดตามเสร็จหรือออกจากฟอร์ม
- action bar ระหว่างฟอร์มเหลือ 64px + safe area ปุ่มสูงอย่างน้อย 44px เนื้อหาท้ายฟอร์มเลื่อนถึงได้เหนือแถบปุ่ม
- รายละเอียดใช้ “ย้อนกลับ” กลับหน้าที่เปิดงานเข้ามาจริง พร้อมคืนตำแหน่งเลื่อนและแท็บเดิม ถ้าเปิดลิงก์งานโดยตรงและไม่มีหน้าก่อนหน้า จะกลับหน้าแรก

## ผลตรวจ

**95/95 checks ผ่าน** ใน Chromium 154.0.8037.92 ตรวจ 8 หน้าที่ 360×640, 390×844, 1366×768 และ 1440×900 ไม่พบ page horizontal scroll, JavaScript error หรือ console error; reduced motion ยังหยุด animation/transition

เป็นการตรวจผ่าน viewport emulation ยังไม่ได้ทดสอบกับ Android/iOS เครื่องจริง รายละเอียดและหลักฐานอยู่ใน Part 5 QA และ prototype-qa/patch-report.json
